## Methodology

1. **Data loading:** imported the dataset and inspected its shape, data types, and summary statistics.
2. **Data cleaning:** handled missing values, removed duplicates, fixed data types, and treated outliers.
3. **Exploratory data analysis (EDA):** studied distributions, relationships between variables, and trends using visualizations.
4. **Insights:** summarised the main findings from the analysis.
